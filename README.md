# Demon Slayer Katana — Stardew Valley 1.6

A new Content Patcher mod project for Stardew Valley 1.6.

## Current scope
- Four katana reference images from the user.
- Initial Content Patcher pack structure.
- No combat abilities, visual effects, or animations yet.

## Planned work
1. Convert the references into clean, transparent pixel-art item sprites.
2. Add the four katana items through Content Patcher.
3. Test the pack in Stardew Valley 1.6 on Android/SMAPI.

The reference images are guides, not final in-game sprites.
